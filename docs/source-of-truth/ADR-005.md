ADR-005 — Canonical Data Separated from Derived Projections


Status: ACCEPTED
Owner: Data / Technology


Context
Timeline, relatórios, search, analytics e RAG precisam de representações otimizadas, mas não podem substituir o registro longitudinal governado.


Decision
Separar explicitamente canonical records de projections/derived stores. Projections devem registrar origem/versão e ser reconstruíveis quando tecnicamente aplicável.


Consequences
+ Reduz risco de perda de provenance e inconsistência semântica.
+ Permite otimização por workload sem transformar índice em autoridade.
- Exige pipelines de sincronização e mecanismos de rebuild.


Rule
Timeline é uma projeção. Search index, warehouse, cache, report materialization e vector index não são fonte canônica de verdade clínica.


Review triggers
Somente revisão de implementação; a separação conceitual permanece requisito de Data Governance.
