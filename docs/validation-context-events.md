# Validação — eventos contextuais

- Domínio recusa categoria sem catálogo, inference como evento original, origem derivada, timezone incoerente e texto fora do limite.
- PostgreSQL mantém registro canônico versionado, associado ao usuário e à provenance, com histórico imutável.
- Nenhuma categoria clínica, finalidade de consentimento ou API foi ativada.
