# Validação da interface inicial de privacidade

- navegação por teclado e sem dependência de rota externa;
- estado vazio declara que não existem consentimentos disponíveis;
- aviso explícito informa que nenhuma escolha é registrada;
- direitos futuros aparecem como indisponíveis, sem controles enganosos;
- layout responsivo sem overflow em 390 × 844;
- nenhum campo aceita informações pessoais ou de saúde.

B8 estabelece somente a superfície visual. Fluxos reais dependem de finalidades, textos, retenção, identidade e endpoints aprovados.
