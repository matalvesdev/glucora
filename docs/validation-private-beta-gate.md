# Validação — gate de private beta

- Documento malformado falha fechado.
- Cada gate exige status permitido, owner e referência de evidência.
- PASS WITH CONDITIONS exige condição e prazo verificáveis.
- Enrollment desabilitado impede readiness mesmo com aprovações.
- CI executa a validação estrita e falha enquanto houver gate sem aprovação, evidência, responsável ou enrollment explícito.
