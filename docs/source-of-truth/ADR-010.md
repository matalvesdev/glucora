ADR-010 — PWA First; Native Mobile on Capability Evidence


Status: ACCEPTED
Owner: Product / Technology


Context
O MVP precisa validar valor longitudinal e preparação para consulta antes de assumir custo de duas plataformas móveis. Web responsiva/PWA cobre a maior parte do fluxo inicial.


Decision
Entregar PWA/web primeiro. Native mobile só será selecionado quando capabilities comprovadas — sensores, health platforms, background sync, push avançado, offline profundo ou distribuição — justificarem.


Consequences
+ Menor custo e maior velocidade de validação.
+ Uma experiência principal no MVP.
- Algumas integrações nativas ficam adiadas.


Not decided
React Native, Flutter, Kotlin/Swift ou outra stack mobile.


Review triggers
Integração com device/OS impossível ou frágil via browser, necessidade de background reliability, user research mostrando limitação relevante ou partner requirement legitimamente estratégico.
