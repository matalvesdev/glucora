ADR-004 — PostgreSQL as Canonical Transactional Source of Truth


Status: ACCEPTED
Owner: Technology / Data


Context
A Glucora precisa preservar integridade, relacionamentos, temporalidade, consentimento, provenance e transações auditáveis sem introduzir múltiplos bancos especializados prematuramente.


Decision
Usar PostgreSQL como fonte de verdade transacional canônica do MVP e fases iniciais. Índices, analytics, search, vector stores e projections permanecem derivados e reconstruíveis quando aplicável.


Consequences
+ Forte consistência e maturidade operacional.
+ Modelo relacional adequado a governança e auditoria.
+ Menor fragmentação de dados.
- Alguns workloads especializados podem exigir stores derivados no futuro.


Not selected as canonical source
Vector DB, graph DB, search engine, warehouse, event log ou time-series store dedicado.


Review triggers
Volume/padrão de acesso comprovadamente incompatível, necessidade de isolamento especializada ou requirement que PostgreSQL não consiga atender de forma razoável.
