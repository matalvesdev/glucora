ADR-002 — React + TypeScript + Vite for Web/PWA


Status: ACCEPTED
Owner: Technology / Product


Context
O MVP precisa de uma interface web responsiva, rápida de desenvolver, acessível e compatível com PWA, sem complexidade de SSR/full-stack framework que não é necessária ao produto inicial.


Decision
Adotar React + TypeScript + Vite para o frontend web/PWA. Tailwind CSS e shadcn/ui compõem a base visual conforme Technology Strategy.


Consequences
+ Ecossistema maduro e alta produtividade.
+ Tipagem consistente com backend TypeScript.
+ Build simples e bom suporte a PWA.
- Capacidades nativas/background continuam limitadas pelo browser.


Not selected
Next.js como fundação principal do MVP; native mobile first.


Review triggers
Necessidade comprovada de capacidades nativas, integração profunda com sensores/health platforms, background execution ou distribuição que o browser não atenda adequadamente.
