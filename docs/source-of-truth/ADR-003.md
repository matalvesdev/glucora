ADR-003 — Node.js + TypeScript + Fastify for Backend


Status: ACCEPTED
Owner: Technology


Context
O backend do MVP precisa de alta produtividade, contratos explícitos, boa performance para APIs e alinhamento de linguagem com frontend, sem framework excessivamente opinativo.


Decision
Adotar Node.js + TypeScript + Fastify para a API/backend principal, com contratos OpenAPI/JSON Schema e arquitetura modular.


Consequences
+ Stack unificada em TypeScript.
+ Fastify oferece baixo overhead e schema-first ergonomics.
+ Boa adequação a APIs e jobs.
- Workloads CPU-bound podem exigir isolamento futuro.


Review triggers
Necessidade comprovada de runtime diferente por domínio, performance incompatível com Node.js, exigência regulatória/operacional específica ou extração de serviços especializados.
