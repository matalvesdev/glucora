13.12 — Implementation Readiness & Definition of Done


Status: Implementation Source of Truth


1. Objetivo
Definir quando o projeto está pronto para iniciar implementação, quando uma capability está concluída e quando o MVP pode avançar para private beta.


2. Repository Readiness Gate
Source of Truth disponível; accepted ADRs identificados; open ADRs não são silenciosamente resolvidos; monorepo structure definida; local setup reproduzível; CI baseline; ownership/instructions para agents; issue/backlog mapping.


3. Story Definition of Ready
Job/problem claro; scope; acceptance criteria; domain owner; dependencies; data/privacy impact; Clinical/AI Risk quando aplicável; contract/API effect; test approach; unresolved decision explicit.


4. Capability Definition of Done
Functional acceptance met; domain invariants preserved; authorization/consent enforced; migration/schema reviewed; provenance/time semantics correct; accessibility/UX states; runtime validation; tests; observability; safe errors/failure mode; security/privacy/clinical/AI review proportional; contracts/docs updated; rollout/rollback understood.


5. Engineering DoD
Lint/typecheck/build/tests green; no critical security findings; no secrets; no unsafe `any`/validation bypass in boundary code without justification; no dead scaffold; migration reproducible; synthetic fixtures only.


6. AI Capability DoD
Intended use/risk registered; approved input/output schema; corpus/source policy; golden/adversarial/privacy/abstention evals; grounding/provenance; guardrails; fallback; telemetry; versioned bundle; Clinical approval when risk requires.


7. Data Capability DoD
Canonical vs projection classification; fact class; temporal fields; provenance; correction semantics; deletion/export impact; dedupe/idempotency; query/index evidence.


8. Privacy/Security DoD
Purpose/legal/consent mapping known; authorization tests; minimization; audit; retention/deletion handling; threat considerations; no unnecessary third-party disclosure.


9. Private Beta Gate
Core cycle Capture → Timeline → Understand/Summarize → Prepare/Share works; privacy rights operational; low-risk AI only if eval-approved; incident/support runbooks; monitoring; backups + restore test; security review; Clinical/Compliance gate; controlled enrollment; feedback path.


10. MVP Exit
Users in target ICP reach real Useful Understanding Cycles; product demonstrates usability/value signal; no unresolved critical safety/privacy/security blockers; operational load supportable; roadmap metrics instrumented. Code completion alone is insufficient.


11. Stop conditions
Pause/revert capability on unsafe clinical output, cross-user data leakage, consent enforcement failure, unreconstructable AI decision path in safety-sensitive workflow, corrupted canonical history, critical unmitigated vulnerability or inability to restore critical data.


12. Review cadence
Reassess implementation blueprint when accepted ADR is superseded, intended use changes, new high-risk capability proposed, major integration/vendor enters or MVP evidence invalidates assumptions.


13. Regra final
Done significa funcional + seguro + governado + testável + operável + documentado. Qualquer uma dessas dimensões ausente mantém o trabalho incompleto.
